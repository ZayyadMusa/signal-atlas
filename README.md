# Signal Atlas

> A visual explorer for understanding recent and historical growing conditions across Nigeria.

## Why I am building this

I am building Signal Atlas because I want to contribute to the agricultural sector and environmental sustainability. Agriculture interests me because it is essential to human survival, food security, and the health of our environment. I want to develop a system that helps farmers and other users understand conditions that could affect their progress before those conditions become serious obstacles. Environmental data should not feel complicated; it should be presented clearly so people can understand what it means and use it confidently. Through this project, I want to learn how to build a complete system from the ground up and develop enough understanding to explain and defend every important technical and design decision.

## The first release

Signal Atlas will initially allow users to:

* Select a Nigerian location.
* Explore monthly rainfall and temperature patterns.
* Understand what each measurement means.
* See where the data came from and how it was processed.
* Use the website comfortably on desktop and mobile.

The first release will not provide crop recommendations, forecasts, or professional agricultural advice.

## Initial locations

* Ibadan
* Kano
* Jos
* Lagos

## Data source

The project will begin with meteorological data from the [NASA POWER Daily API](https://power.larc.nasa.gov/docs/services/api/temporal/daily/).

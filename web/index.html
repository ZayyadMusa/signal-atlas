What each report includes

  • The location and period covered.
  • A simple explanation of the conditions.
  • The measurement units.
  • Missing-data notices when necessary.
  • The source of the data.

Where the data comes from

Signal Atlas uses historical meteorological data from the NASA POWER Daily API. Each report explains how the data was retrieved and processed.

The first release will describe historical conditions. It will not provide forecasts, crop recommendations or professional agricultural advice.

Signal Atlas is an educational environmental-data project.
